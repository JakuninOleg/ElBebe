# Отзывы родителей

На главной и странице команды используется `ParentReviews.astro`. Сейчас он ведёт в реальную карточку сада на Яндекс Картах. Чужие отзывы, придуманные цитаты, рейтинг и количество оценок не добавлялись.

Подготовленный источник: `src/data/parent-reviews.ts`. Поля записи: `id`, `author`, `text`, `rating`, `sourceUrl`, `approved`. Исходный текст и автора сохранять, не редактировать смысл отзыва. `sourceUrl` должен вести к отзыву в карточке организации `154599785417`. Публикуются только проверенные записи с `rating: 5` и `approved: true`; дубли исключаются. На сайте они обозначаются как выбранные пятизвёздочные отзывы, рядом остаётся ссылка на всю ленту. Не выдавать рейтинг выбранных отзывов за общий рейтинг организации.

Автоматическая загрузка не подключена: нужен согласованный источник данных и доступ к нему. Для такой загрузки адаптер должен наполнять этот же список во время сборки, сохраняя проверку источника и отбора. Секретный ключ хранить только на сервере сборки. Не парсить Яндекс и не приобретать стороннюю услугу без отдельного решения.

Яндекс описывает готовый виджет, который можно получить через «Поделиться» в карточке организации: https://yandex.ru/support/maps/ru/concept/get-map-reference.html . В документации указана ширина 300–760 px и рекомендуемая высота от 500 px. Настройка отбора только пятизвёздочных отзывов в этой инструкции не описана; такой виджет нельзя считать реализацией заданного фильтра. Вместо обещания автоматического импорта пока сделаны собственный компонент, проверяемый контракт и отбор.

На странице контактов подключена карта организации через iframe Яндекс Карт с ленивой загрузкой. Ключ Maps JS API для этого варианта не добавляется. Ссылка на полную карту остаётся рядом.

Проверка: `node --test scripts/parent-reviews.test.mjs`.
