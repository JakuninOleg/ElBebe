# Отзывы родителей

На главной и странице команды используется `ParentReviews.astro`. По прямому запросу пользователя 22.10.2026 добавлены три проверенных фрагмента содержательных пятизвёздочных отзывов. Все цитаты дословные; пропуск в третьей обозначен многоточием. Полные тексты открываются в исходной карточке. Общий рейтинг и число оценок на сайте не заявляются.

Источник: `src/data/parent-reviews.ts`. Поля: `id`, `author`, `text`, `rating`, `sourceUrl`, `approved`, `source`, `date`, `published`, `topic`. Фильтр допускает только HTTPS-ссылки на отзывы Яндекса для организации `154599785417` и 2ГИС для организации `70000001044912349`. Публикуются только проверенные записи с `rating: 5` и `approved: true`; дубли исключаются. Заголовки тем — редакционные, они не заключены в кавычки и не выдаются за слова автора.

Проверено в браузере 22.10.2026:

- Наталия Ермошкина — Яндекс, 15.05.2025, 5/5. Проверены метаданные Review и ссылка из окна «Поделиться отзывом».
- OLGA Ikonnikova — 2ГИС, 01.03.2022, пять заполненных звёзд. Ссылка ведёт в общую ленту: прямой публичный permalink этого отзыва интерфейс не предоставил. Автор сохранён ровно как в 2ГИС.
- Настасья Евглевская — Яндекс, 30.05.2025, 5/5. Отзыв дополнительно сопоставлен с публичной страницей автора https://yandex.ru/maps/user/INMYSEA и названием сада в ней.

Обе карточки имеют актуальное название El Bebe / «Эль Бебе» и адрес Виноградная, 2/3. В старых отзывах встречается прежнее название Bambini; в выбранных фрагментах название не подменялось. Личные медицинские сведения из других отзывов не используются. Даты отзывов видимы, исторические впечатления не превращаются в текущие обещания услуг.

Подборка ручная, автоматическая синхронизация не подключена. Для будущей автоматизации нужен согласованный источник и доступ к нему. Адаптер должен наполнять этот же список во время сборки, сохраняя проверку источника и отбора. Ключ хранить только на сервере сборки. Платные сервисы не подключались.

Яндекс описывает готовый виджет, который можно получить через «Поделиться» в карточке организации: https://yandex.ru/support/maps/ru/concept/get-map-reference.html . В документации указана ширина 300–760 px и рекомендуемая высота от 500 px. Настройка отбора только пятизвёздочных отзывов в этой инструкции не описана; такой виджет нельзя считать реализацией заданного фильтра. Вместо обещания автоматического импорта пока сделаны собственный компонент, проверяемый контракт и отбор.

В общем футере и на странице контактов подключена настоящая карта организации через iframe Яндекс Карт с ленивой загрузкой. Ключ Maps JS API для этого варианта не нужен. Ссылка на полную карту остаётся рядом.

Проверка: `node --test scripts/parent-reviews.test.mjs`.
