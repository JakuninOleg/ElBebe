## Поведение

Плеер на странице показывает обложку 4:5. MP4 имеет `preload="none"`, автозапуска нет. Запуск — по отдельной кнопке; затем доступны стандартные пауза, громкость, перемотка и полный экран. Видео вписывается целиком, включая вертикальный ролик младшей группы. Иллюстрированная обложка не обрезается. Без JavaScript остаются стандартные элементы управления браузера. Ошибка загрузки выводит ссылку на самостоятельное открытие файла.

Проверки: `npm run typecheck`, `npm run build:showcase`, затем `node --test scripts/group-videos.test.mjs`. Тесты проверяют соответствие файлов группам, отсутствие автозапуска и заглушек, наличие обложек, снижение веса и расположение индекса MP4 перед видеоданными.

Полная проверка FFmpeg: все три web-файла декодируются без ошибок; длительности 142.85 / 210.43 / 88.03 секунды и разрешения совпадают с исходниками. SHA-256 сжатых AAC-пакетов совпадает до и после подготовки. Общий размер уменьшился с 41.26 до 30.48 МБ, на 26%.

В браузере проверены запуск и пауза всех трёх роликов, готовность декодера, клавиатурное управление и мобильная компоновка. До запуска `readyState=0`, воспроизведение не начинается. Для старшей группы дополнительно проверен запуск при ширине 375 CSS px. Формы, утверждённый логотип и остальные изображения не менялись.
