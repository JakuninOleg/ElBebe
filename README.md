# Эльбебе — Astro + EmDash

Сайт детского сада El Bebe в Сочи. Адаптивная вёрстка, русские тексты, страницы групп, стоимости, распорядка дня, команды, пространства, вопросов и контактов.

## Полная версия на VPS

`Dockerfile` и `compose.yaml` собирают сайт вместе со штатной EmDash. SQLite, медиатека, заявки и сессии находятся в постоянном томе; HTTPS обеспечивает Caddy. Существующие базы и ключи переносятся приватным пакетом и не входят в образ. Первый импорт, запуск, бэкап и восстановление: [инструкция Docker/VPS](docs/DOCKER-VPS.md).

## Показ на Vercel

Репозиторий настроен на **статическую демонстрационную версию**, чтобы показать сайт заказчику без отдельной базы данных и хранилища.

1. В Vercel выберите **Add New → Project** и импортируйте `JakuninOleg/ElBebe`.
2. Корень проекта — корень репозитория, Node.js — **24.x**.
3. Команда сборки `npm run build:showcase` и каталог `dist-showcase` уже заданы в `vercel.json`. Переменные окружения для показа не нужны.

Демоверсия содержит тот же дизайн и страницы, использует проверенный снимок опубликованного содержимого. Админка, пользовательские сессии, база и API заявок в неё не входят. Поля формы доступны, работает общая маска телефона и проверка заполнения. Статическая версия не собирает обращения: при отправке предлагает связаться с садиком, без фиктивного подтверждения. Страницы закрыты от индексации. Это ссылка для согласования, а не запущенный сайт садика.

Локальная проверка той же сборки:

```sh
npm ci
npm run build:showcase
npm run preview:showcase
```

После публикации изменений в локальной CMS обновите снимок и загрузите его в Git:

```sh
npm run snapshot:showcase
npm run build:showcase
```

Экспорт читает только опубликованные версии шести коллекций сайта, не меняет SQLite и не переносит аккаунты, черновики, ключи или заявки. Изображения для показа должны иметь подготовленные копии в `public/images/el-bebe`.

## Полная локальная версия с CMS

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4321
```

Сайт: `http://127.0.0.1:4321/`. EmDash: `http://127.0.0.1:4321/_emdash/admin`.

Основная конфигурация `astro.config.mjs` сохраняет Node.js, SQLite и локальную медиатеку. `npm run build` собирает эту серверную версию. На новой машине требуется штатная установка EmDash; локальная база, секреты и загрузки через Git не передаются.

В полной версии форма сохраняет заявки в отдельную приватную SQLite-базу. В штатной EmDash добавлен раздел «Работа садика»: заявки родителей и готовые документы для печати (расписание, дни рождения, стоимость). Внешние уведомления ещё не подключены. Настройка приватного пути и проверка доступа описаны в [инструкции запуска](docs/OFFICE-RUNBOOK.md). Состав будущих простых полей директора и схема доставки на VPS — в [предложении по CMS](docs/CMS-DIRECTOR.md).

Рабочий сайт с редактированием в EmDash требует отдельного решения для постоянного хранения данных. Vercel-конфигурация этого репозитория предназначена только для статического показа. О выборе базы: [EmDash](https://docs.emdashcms.com/deployment/database/). О статической публикации Astro: [Vercel adapter guide](https://docs.astro.build/en/guides/integrations-guide/vercel/).

## Материалы и ограничения

На сайте используется утверждённый русский векторный логотип. Подтверждены образовательная лицензия, возможность оплаты материнским капиталом, онлайн-видеонаблюдение для родителей, работа 24/7 и включённые питание и занятия. Цены и программы приведены по материалам сада. Возрастные границы, юридические реквизиты и отзывы не придуманы.

По запросу владельца от 21.10.2026 при отсутствии опубликованных сотрудников показаны четыре временные карточки по ролям с ранее сгенерированными портретами. Имена, стаж и квалификация не выдуманы. Данные находятся отдельно в `src/data/preview-educators.ts`; реальные записи CMS автоматически заменяют временный набор. Фотографии пространства также пока иллюстративные. Видео групп ожидают выбранных материалов, реквизиты и документы — сведений сада.
