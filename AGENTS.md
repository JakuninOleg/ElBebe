# OJ EmDash

Локальный стартовый проект Astro + EmDash. На первом этапе показываем штатный интерфейс без редизайна.

## Запуск

npm run dev -- --host 127.0.0.1 --port 4321

Админка: http://127.0.0.1:4321/_emdash/admin

Локальный вход для разработки: dev-bypass, выведенный сервером Astro. Не использовать его для production.

## Направление

Изменяем встроенную админку EmDash, а не создаём отдельный клиент через API. Сохраняем штатные авторизацию, редактор, CRUD и медиа. Цель: русский язык, визуальный язык OJ CMS, понятная навигация, формы и рабочий стол. Изменения общей оболочки могут требовать патчей исходников пакета и проверки обновлений.


Публиковать только по прямому запросу пользователя. 15.10.2026 разрешена загрузка исходников в JakuninOleg/ElBebe и подготовка статического показа на Vercel. Полная CMS продолжает работать локально; в showcase нет админки и сбора заявок. Не выводить .env и секреты. Не коммитить SQLite, uploads, пользовательские сессии и ключ шифрования.

По запросу пользователя от 14.10.2026 реализуем локальный сайт El Bebe на Astro + EmDash по предоставленным desktop/mobile референсам. Сохраняем существующую базу и штатную админку. Фотографии для макета можно генерировать; нельзя выдавать их за реальные помещения или сотрудников. Не придумывать отзывы, тарифы, возрастные ограничения и реквизиты лицензии. Подтверждены лицензия и возможность оплаты маткапиталом, конкретные реквизиты ещё нужны.
